Counter the enemy

A companion for Deadlock, on your PC or in your browser. Tell it who you’re up against and it shows you exactly what to buy, and how to play the matchup.

You pick the enemy hero. Counterlock shows the counter items split into lane, mid and late game, plus short tips for the hero you are playing. All of it reads from plain profile files, so the advice keeps up with the patch instead of going stale.

It runs on Windows and Linux, opens in a second, and stays out of your way while you play. It is free.

Editing your own counters

Every bit of advice lives in a profile you can change. You do not need to touch code.

  1. Open Settings, then Profile editor. A separate editor window opens.
  2. Choose an enemy hero on the left to edit that matchup.
  3. Fill in the items for lane, mid and late. Add a short note to any item if it needs one.
  4. Add tips for the hero you play into that matchup. Leave blank anything you don't have.
  5. Click Save, or Save as to keep it as a new profile. The app loads your changes straight away.

Using a profile someone else made? Download one from Counter Profiles, then open Settings and Load from file.

Prefer a text editor? The profile is a simple .xml file. Edit it in anything you like and Counterlock re-reads it every time it starts. Keep a backup before big changes.

Install on Windows

  1. Click Windows above to download Counterlock.exe.
  2. Double-click it to run. Nothing gets installed, it just opens.
  3. The first time, Windows may show a blue "Windows protected your PC" box, because the app is not code-signed yet. Click More info, then Run anyway.
To update later, download the new .exe and replace the old one. Your settings are saved separately, so they carry over.
Linux single binary · x86_64

Verify your download: each release lists a checksum next to the file.

Install on Linux

  1. Click Linux above to download the Counterlock file.
  2. Move it to a folder where it can stay, like Applications in your home folder. The app menu entry points to this spot.
  3. Open a terminal in that folder and make it executable: chmod +x Counterlock
  4. Start it with ./Counterlock. The first start adds Counterlock to your app menu with its icon, so after that you can open it from the menu like any other app. If the icon doesn't show at once, start it one more time.
To update, put the new file in the same folder over the old one and run chmod +x Counterlock again. Your settings carry over.
Won't start and mentions a platform plugin? Install the Qt libraries once: sudo apt install libxcb-cursor0 libxkbcommon0 on Debian or Ubuntu. Most desktops already have them.
App icon Counterlock sets up its own icon, so you only need this for a shortcut you make yourself. PNG  ·  SVG

Removing Counterlock? Also delete ~/.local/share/applications/counterlock.desktop and the menu entry goes away.

Privacy & rules

No ads, no tracking, and you can delete everything yourself.

What we keep

Browsing and downloading don't need an account, and nothing about you is saved when you do.

With an account, we keep your username, email, password (stored as a secure hash nobody can read), the profiles you upload and the ratings you give. Your email is never shown to anyone. We only use it to sign you in and to send account emails, like confirmations, password resets and a note when you upload. We keep all this because you need it to have an account.

Failed sign-ins are counted for 15 minutes to stop password guessing. If you report a profile, the admin sees the report and your username; reports are deleted after 90 days.

Where it's kept

Accounts, profiles and ratings are stored with Supabase on servers in the EU, and emails are sent through Resend. The site runs on GitHub Pages, which logs visitor IP addresses for security, like any web host.

All traffic to the site and the database is encrypted (HTTPS), and the database only lets each account see its own details. Nobody but the site's admin can open the database itself.

Messages from the contact form are emailed to us through Resend so we can reply. The site itself keeps no copy, only a scrambled version of your IP address for two days, to stop spam. Tips go through Ko-fi, under its own privacy policy.

No cookies. Signing in saves a login token in your browser, and signing out removes it.

How long

Until you delete your account (Account, then Delete account). Everything is removed right away, except your username: it stays reserved for 6 months so nobody can pretend to be you. Unconfirmed signups are removed after 3 days, and sign-in counters within a day.

Your rights

You can see, fix or delete your data at any time, mostly from your account settings. For anything else, send a message through the Support the developer page. You can also complain to a data protection authority.

Rules

  • You need to be 13 or older to make an account.
  • Keep profiles about Deadlock.
  • No slurs, hate, harassment or personal info in usernames or profiles.
  • Profiles need at least 3 filled-in matchups.
  • You can share one new profile an hour, and update each profile every 10 minutes.
  • See something that breaks these rules? Use Report on the profile.
  • Only upload your own work, or work you're allowed to share.
  • Anything that breaks the rules can be removed without warning.
